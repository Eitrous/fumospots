## 与当前 PMTiles 要素的对应关系

当前 PMTiles 的 `boundaries` 图层以 `brk_a3=B00` 标识该组争议边界：

- 北侧线：`kind=country`、`kind_detail=2`、`disputed=true`。该线位于西藏主体与藏南之间，不作为本项目的中国国界显示。
- 南侧外缘线：`kind=unrecognized_country`、`kind_detail=3`。其走向用于与上述 2024 年标准地图交叉核对，渲染时同样移除，改由标准地图 `国界` 几何统一绘制。

PMTiles 在 6 级以上会省略 `brk_a3`，但该组要素仍保留 `disputed=true`、`sort_rank=288`。样式因此同时使用低缩放属性和经逐级瓦片核验的空间范围过滤，不再使用依赖底色的线条遮罩；明暗主题共用同一组要素级规则。8 级以上出现的 `kind=region/county` 原阿鲁纳恰尔邦内部界线不绘制：完全落在藏南标准地图范围内的要素直接按空间关系排除；Planetiler 合并成跨范围 `MultiLineString` 的残留要素，则使用当前归档 z8-z13 核验得到的稳定要素 ID 家族前缀，并叠加藏南周边空间范围进行局部排除。z8 另有 4 个要素因大瓦片合并而延伸到约北纬 25.78°，仅对这 4 个完整 ID 使用单独的南侧扩展范围。这样不会因 ID 家族在别处复用而影响全球其他行政界线，也不会把扩展范围应用到其他县界。

山南标准地图 `国界` 要素在藏南西端之后继续包含既有的中不边界。官方覆盖层在其与当前底图中不边界的东端接合处停止，避免同一段国界因两套数据精度差异而显示成两条平行线；林芝段完整保留。

县级名称按照标准地图和地名公告采用：错那市、隆子县、墨脱县、察隅县。底图中的县级驻地标签使用 Wikidata ID 与原始名称双重匹配，避免因单一语言字段缺失而漏改。

山南市、林芝市标准地图 MDB 中位于藏南范围的 `居民地` 图层共核得 35 个点位；应用直接使用这些点位的名称和坐标。县级城市标点从 z8 开始显示，村镇居民点从 z10 开始显示，避免低缩放视野过早出现密集标点。为避免高缩放级别重新出现另一套乡镇、村庄名称，原 PMTiles `places` 图层在范围面内的居民地标签统一不绘制，只保留标准地图点位。该范围面仅用于标签筛选，不作为国界展示；其北缘取当前瓦片待排除线，南缘取标准地图国界，西缘沿相邻不丹边界闭合。

## 发布注意事项

标准地图页面说明，对标准地图内容进行编辑改动后公开使用，应依法履行地图审核程序。本项目中的交互式样式属于改编显示，上线前仍需按适用规定送审。
